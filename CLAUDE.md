# Claude Code Project Rules

## Working Principles

- **Informed decisions over guesswork**: Read documentation and code to KNOW what's correct, don't assume or speculate
- When confused, read the plan docs, existing code, and protobuf definitions before making changes

## Git Commits

- Commit messages should be **4 lines maximum** (subject + blank + 1-2 body lines)
- Do NOT include the `Co-Authored-By` footer
- Keep it concise: subject line describes what, body line explains why if needed
